# Gabagiving

**Tony Soprano Thanksgiving** — a linear retro top-down pixel-art Thanksgiving web game parody for desktop and mobile browsers.

## Play

Open `index.html` through any static web server, or deploy the repository directly to Vercel.

- Move: WASD / arrow keys / mobile touch stick
- Interact and advance dialogue: E, Space, Enter, or mobile A
- Mobile B is the secondary bonus key on the ending screen
- M toggles sound

The game uses original programmatic pixel art and synthesized dialogue grunts/music; there are no copied show assets.

## Structure

- `index.html` — static app shell
- `styles.css` — responsive canvas and mobile controls
- `js/game.js` — story scenes, interactions, minigames, and rendering
- `js/sprites.js` — programmatic pixel characters and props
- `js/audio.js` — synthesized voices, effects, and music
- `assets/mockup.png` — original visual direction mockup
